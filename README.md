# CYBERCORE — Beyond Human

A responsive cybernetic-themed landing page concept built with semantic HTML, modern CSS and vanilla JavaScript.

## Features
- Responsive desktop, tablet and mobile layouts
- Custom CSS cybernetic humanoid illustration (no image assets required)
- Animated radar, holographic cube, scan/orbit effects and subtle motion
- Mobile navigation menu with accessible expanded state
- Email waitlist form with client-side validation and confirmation state
- Reduced-motion accessibility support
- Semantic sections, accessible labels and responsive typography

## Run locally
No build step or package installation is required.

1. Clone or download this repository.
2. Open `index.html` in a browser, or run a local server:

   ```bash
   python -m http.server 8000
   ```

3. Visit `http://localhost:8000`.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive layout, theme and animations
- `script.js` — mobile navigation and waitlist interaction

## Note
The waitlist form is a front-end demo only. It validates an email and displays a confirmation, but does not send or store addresses. Connect a backend or form service before production use.
